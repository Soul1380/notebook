# Mac v1.0.0 功能基线

此目录冻结当前 Windows 1.0.8 的功能和源码，作为 Mac v1.0.0 的移植起点。source.zip 是源码快照，不是 Mac 安装程序。Windows 的 version.json 保持不变。

共用范围：画布笔迹与图形、注解、文本格式、图片及工程导入导出、四种工具栏样式、深色模式、插件配置、首选项与讨论页面。

需适配 macOS：浮动球与窗口预加载、运行窗口栏与切换、系统快捷键、剪贴板、报表通知、安装卸载、独立更新器和异常恢复。PowerShell、WinForms 和 Windows 可执行文件不能直接用于 macOS。

发布策略：Windows 为主要迭代版本；Mac 按成熟功能阶段性同步。Mac 首个正式发布版本为 1.0.0。当前尚未生成或测试 macOS 可运行程序。
