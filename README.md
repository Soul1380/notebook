# 手写笔记本

Windows 手写画板，支持笔迹、图片、文本框、可定位的注解框和工程文件。

## 安装与启动

从本仓库的 Releases 下载 Windows 安装程序，选择一个有写入权限的安装位置。安装版需要 64 位 Windows 10/11 和 Microsoft Edge；运行安装目录中的 `HandwritingNotebook.exe`，再点击浮动球打开画板。右键浮动球可以更换皮肤、打开软件所在目录或退出。

普通启动时画布为空白；自动更新重启后会恢复更新前的画布和视图位置。需要继续编辑时，请在“文件”标签中打开 `.notebook` 工程；也可选择“恢复上次画布”恢复本机自动备份。开始新编辑可能覆盖自动备份，建议先保存工程。

旧版和新安装目录各自保存浏览器数据。迁移时请在旧版导出 `.notebook` 工程，再在新版中打开。

## 画布和工具

- 左键拖动书写；在空白处长按片刻再拖动，可移动画布。鼠标滚轮以指针为中心缩放。
- 选择画笔、局部擦除、图形、图片或文本框；选中对象后按 Delete 删除，Ctrl+Z 撤回。图形拖动时按住 Shift，可从中心展开。
- Windows 截图后激活窗口并按 Ctrl+V 可粘贴图片。文本框支持宋体和自动换行，双击可编辑。
- 创建注解框后，双击上方标签重命名；通过“注解”标签搜索并定位。按住 Ctrl 拖动框内部，可移动注解框、框内笔迹和完整位于框内的图片与文本框；跨越边界的笔迹仅移动框内部分。
- 在画布上按住右键并向目标方向拖动，可使用轮盘选择常用工具。也可以右键单击后点击工具。
- PNG 导出按内容范围裁切，四周各预留约 0.1 厘米（按 96 DPI 换算）。工程文件保留可编辑对象。

## 设置与快捷键

“窗口 → 首选项”中可按类别设置快捷键，也可调整 UI 比例、画布点阵、界面颜色和提示显示。左下角半透明提示框跟随当前工具标签，只显示部分已设置的快捷键。

首选项还可选择工程文件保存目录。Shift+F 打开快捷查询，可在 Chrome 中搜索，或复制问题并打开 ChatGPT；ChatGPT 中的聊天需要手动选择。

## 自动更新

从 1.0.1 开始，安装版启动后、运行期间每隔 30 分钟检查本仓库的最新正式 Release。发现新版本时，软件自动下载 `HandwritingNotebook-update.zip`，并使用 GitHub 提供的 SHA-256 校验值验证。下载校验完成后，停止操作 10 秒且没有正在进行的书写、文本编辑或注解重命名时，程序自动保存当前画布、关闭、备份旧程序文件、安装更新并重新启动，随后恢复画布和缩放位置。画布备份失败时不会关闭程序。前往“窗口 → 检查更新”查看当前版本和状态，也可手动点击“安装并重启”。网络失败会在下一次定时检查时重试。用户的工程和设置不会被更新包替换。

1.0.0 仍需手动点击一次“安装并重启”升级至 1.0.1；不含更新功能的更早版本需运行新版安装程序。以后发布版本时递增 `version.json`；仓库的 GitHub Actions 工作流会构建安装程序和更新包并创建对应 Release。

## 构建

`packaging/Build.ps1` 在 Windows 上使用系统 .NET Framework 编译器，需指定 Node.js 可执行文件、临时目录、安装程序输出路径，以及可选的更新包输出路径。开发用的 `index.html` 可以直接在浏览器打开；窗口切换和自动更新仅在安装版中可用。

## 卸载

安装目录内运行 Uninstall.exe，先保存工程并通过浮动球右键菜单退出软件。卸载仅删除程序文件，保留工程、设置、自动备份和其他个人文件。通过自动更新升级后，重新启动浮动球即可生成卸载程序。

浮动球拖到距屏幕左右边缘 100 像素以内并松开，会自动吸附；鼠标离开后隐藏到边缘，移回时展开。
