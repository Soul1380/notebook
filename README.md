# 手写笔记本

双击 `index.html` 即可在浏览器中使用。按住鼠标左键书写；在空白处按住约半秒再拖动画布。点击色块选择颜色；擦除工具会擦除整条笔迹。点击撤回或按 Ctrl+Z 撤回；按住 Shift 拖动画直线。点击保存导出 PNG。导出尺寸按全部笔迹范围计算，四周分别增加 0.1 厘米（按 96 DPI 换算）。

笔迹会自动保存在当前浏览器的本地存储中。清除浏览器数据可能删除笔迹，建议及时导出 PNG。

## 版本管理

此目录是 Git 仓库。后续添加或修改程序前，先提交当前版本；每次完成更改后再次提交。可用 `git log` 查看版本，并通过 Git 恢复旧版本。


擦除范围可通过顶部滑块调整，擦除仅影响接触到的部分。图形菜单提供直线、长方形、正方形、椭圆、圆形和三角形。打开首选项可设置快捷键和直线修饰键。

## 桌面版
双击“启动桌面版.cmd”打开独立窗口（需要 Microsoft Edge 和 Node.js）。窗口支持全屏、最小化、最大化或恢复，以及置顶。置顶表示窗口保持在其他普通窗口上方。拖动绘制图形时按住 Shift 可从起点向四周展开。桌面版与直接打开文件的浏览器版各自保存笔记，互不共享。

## 浮动球和工程文件
双击“启动桌面版.cmd”后先出现浮动球，点击打开笔记窗口。拖到屏幕左右边缘后会自动缩入边缘；鼠标移到露出的部分可展开。右键浮动球可打开笔记或退出浮动球。
工具栏按绘制、颜色、文件、窗口分组，窗口较窄时可以横向滚动。
“保存工程”导出 .notebook 文件，保留可编辑笔迹；“打开工程”可重新载入。“新建”清空当前画布，操作前请先保存工程。PNG 仍用于导出图片。

## 启动与工具组
建议双击“启动浮动球.vbs”，它会隐藏 PowerShell 窗口。浮动球可拖动到屏幕任意位置，靠近左右边缘会吸附，闲置时缓动缩入边缘；点击后笔记窗口会平稳显示。每个工具组有自己的横向滚动条，窄窗口下工具组收缩，按钮不会缩小。

## 图片、文字和缩放
滚轮以鼠标位置为中心缩放画板。激活笔记窗口后可按 Ctrl+V 粘贴截图，或在图片工具组中插入图片；选择对象后可拖动，拖动右下角可缩放，图片也可用放大、缩小按钮。文本框工具拖出矩形后输入文字，双击已有文本重新编辑，文字使用宋体并自动换行。
首选项可选择工程保存文件夹，使用“保存工程”时输入文件名；首次或重新启动后可能需要再次授予目录写入权限。不设置目录时工程下载到浏览器默认位置。工程保存为版本 2，同时支持打开旧版工程。


## 工具栏和快捷查询
启动时画布为空白；如需恢复此前浏览器里的自动备份，请在“文件”标签选择“恢复上次画布”。开始新编辑可能覆盖上次自动备份，请先恢复并保存工程。工具栏分标签，点击标签显示对应工具，窗口变窄时按钮自动换行。
鼠标位于窗口内时按 Shift+F，输入内容后可选择在 Chrome 中百度搜索，或复制问题并打开 ChatGPT。ChatGPT 选项目前需要手动选择聊天并粘贴发送，暂不能按工程自动关联聊天。

## 运行窗口栏
桌面版左侧显示当前可切换的可见窗口，点击图标切换；悬停可查看窗口标题。后台进程和无可见窗口的程序不会显示。不能提取图标时显示通用图标。选中图片后按 Delete 可删除，Ctrl+Z 可撤回删除。

## 颜色与浮动球皮肤
颜色标签保留固定颜色，RGB、明暗和不透明度滑块可调整画笔及新文本颜色；松开滑块或选取固定色后，颜色会保存在“最近使用”中，最多显示 10 种。最近颜色保存在当前浏览器；工程文件会保存笔迹及文本的颜色和不透明度。
右键浮动球选择“皮肤颜色”，可使用预设或自定义颜色。皮肤配置保存在项目目录的 .ball-settings.json 中。
